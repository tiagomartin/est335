Parte I : Regressão

Regressão Local e Introdução a RKHS

De onde partimos?

Até aqui, estimamos \(r(x)=E[Y\mid X=x]\) usando vizinhanças.

KNN: \[\widehat r_K(x_0)=\frac1K\sum_{i\in N_K(x_0)}Y_i\]

Nadaraya–Watson: \[ \widehat r_h(x_0)= \frac{\sum_i K((x_i-x_0)/h)Y_i} {\sum_i K((x_i-x_0)/h)} \]

A pergunta desta semana

Nadaraya–Watson produz essencialmente uma constante local.

Por que não ajustar uma pequena regressão na vizinhança de \(x_0\)?

Depois, iremos além: como regularizar diretamente uma função flexível?

Regressão Polinomial Local

Nadaraya–Watson revisitado

Em torno de \(x_0\), suponha: \[Y_i\approx\beta_0(x_0)\]

Estimamos: \[ \min_{\beta_0} \sum_i K\left(\frac{x_i-x_0}{h}\right)(Y_i-\beta_0)^2 \]

A solução é a média ponderada de Nadaraya–Watson.

\[\boxed{\text{Nadaraya–Watson = regressão constante local}}\]

Em vez de uma constante…

Na vizinhança de \(x_0\): \[ r(x)\approx\beta_0(x_0)+\beta_1(x_0)(x-x_0) \]

Assim combinamos: \[ \boxed{\text{Mínimos Quadrados}} + \boxed{\text{Vizinhança}} + \boxed{\text{Pesos Kernel}} \]

Regressão linear local

\[ \boxed{ (\widehat\beta_0,\widehat\beta_1) = \arg\min_{\beta_0,\beta_1} \sum_i K\left(\frac{x_i-x_0}{h}\right) [y_i-\beta_0-\beta_1(x_i-x_0)]^2 } \]

e \[\boxed{\widehat r(x_0)=\widehat\beta_0(x_0)}\]

Por que centralizar em \(x_0\)?

Como \(x-x_0=0\) exatamente no ponto de interesse, \[ \widehat r(x_0)=\widehat\beta_0 \]

A interpretação da predição fica imediata.

A reta muda com \(x_0\)

Para cada ponto: \[ x_0 \rightarrow \text{novos pesos} \rightarrow \text{nova regressão} \rightarrow \widehat r(x_0) \]

Repetindo esse processo, obtemos uma curva suave.

Regressão polinomial local

Generalizamos: \[ r(x)\approx \beta_0+ \beta_1(x-x_0)+\cdots+ \beta_d(x-x_0)^d \]

Os coeficientes são estimados por mínimos quadrados ponderados localmente.

Casos importantes

\[d=0\Rightarrow\text{constante local / Nadaraya–Watson}\]

\[d=1\Rightarrow\boxed{\text{regressão linear local}}\]

\[d=2\Rightarrow\text{regressão quadrática local}\]

Em geral, graus baixos são suficientes.

Local não significa grau elevado

A flexibilidade vem de ajustar um modelo diferente em cada vizinhança.

Logo, normalmente não precisamos de polinômios globais de grau elevado.

\[\boxed{d=1\text{ ou }d=2\text{ costuma ser suficiente}}\]

O hiperparâmetro continua sendo \(h\)

\[ h\downarrow \Rightarrow \text{vizinhança menor} \Rightarrow \text{maior flexibilidade} \]

\[ h\uparrow \Rightarrow \text{vizinhança maior} \Rightarrow \text{maior suavização} \]

Viés × variância novamente

\(h\) pequeno:

  • menor viés;
  • maior variância.

\(h\) grande:

  • maior viés;
  • menor variância.

O mesmo princípio de controle de complexidade reaparece.

Efeito de fronteira

Nas extremidades do domínio, a vizinhança é assimétrica.

Uma constante local pode apresentar viés importante.

A regressão linear local consegue adaptar a inclinação da função.

\[\boxed{\text{vantagem importante da regressão linear local}}\]

Voltando ao LOESS

Agora podemos entender LOESS como: \[ \boxed{ \text{vizinhança} + \text{pesos pela distância} + \text{regressão polinomial local} } \]

Portanto, LOESS pertence à mesma família dos métodos locais.

Em várias dimensões

Podemos ajustar localmente: \[ Y_i\approx\beta_0+ \sum_{j=1}^p\beta_j(X_{ij}-x_{0j}) \]

Mas: \[ \boxed{p\uparrow\Rightarrow\text{vizinhanças tornam-se esparsas}} \]

A maldição da dimensionalidade permanece.

Regularização em Espaços de Funções

Uma mudança de perspectiva

Semana 4: \[\text{regularizar coeficientes}\]

Semanas 5–6: \[\text{estimar funções flexíveis}\]

Agora combinaremos as duas ideias.

Podemos regularizar uma função?

Em vez de penalizar somente \(\beta_1,\ldots,\beta_p\): \[ \boxed{ \text{ajuste aos dados} + \lambda\times\text{complexidade de }f } \]

Já vimos isso!

No smoothing spline: \[ \boxed{ \sum_i(y_i-f(x_i))^2 + \lambda\int[f''(t)]^2dt } \]

O primeiro termo mede ajuste.

O segundo penaliza a curvatura da função.

Do Ridge para funções

Ridge: \[RSS+\lambda\|\boldsymbol\beta\|_2^2.\]

Agora: \[ \boxed{ \sum_i(y_i-f(x_i))^2+ \lambda\|f\|_{\mathcal H}^2 } \]

\(\mathcal H\) representa um espaço de funções admissíveis.

O que é \(\mathcal H\)?

Nesta disciplina, pense em \(\mathcal H\) como:

um conjunto estruturado de funções no qual conseguimos medir tamanho ou complexidade.

A norma \(\|f\|_{\mathcal H}\) desempenha papel análogo a \(\|\boldsymbol\beta\|_2\) no Ridge.

RKHS

Um Reproducing Kernel Hilbert Space é um espaço de funções com uma estrutura especial associada a um kernel.

\[ \boxed{\text{kernel}\longleftrightarrow\text{espaço de funções}} \]

A construção matemática completa fica no material complementar.

Atenção: dois significados de kernel

Kernel de suavização

Semana 5: \[K((x-x_i)/h)\]

Serve para definir pesos locais.

Atenção: dois significados de kernel

Kernel em RKHS

\[K(x,x')\]

Representa uma relação de similaridade compatível com um espaço de funções.

\[\boxed{\text{mesma palavra, papéis matemáticos diferentes}}\]

Kernel linear

\[ K(x,x')=x^\top x' \]

Esse caso se conecta diretamente à geometria dos modelos lineares.

Kernel polinomial

\[ K(x,x')=(c+x^\top x')^d \]

As funções de base da Semana 3 reaparecem de forma implícita.

Kernel Gaussiano / RBF

\[ \boxed{ K(x,x')= \exp[-\gamma\|x-x'\|^2] } \]

Pontos próximos apresentam maior similaridade.

Mas esse kernel não está simplesmente calculando uma média local.

O resultado central

Mesmo procurando \(f\) em um espaço extremamente rico, sob condições apropriadas a solução regularizada possui forma: \[ \boxed{ \widehat f(x)= \sum_{i=1}^n\alpha_iK(x,x_i) } \]

Esse é o conteúdo essencial do Teorema do Representer.

Por que isso importa?

O problema original envolve: \[f\in\mathcal H,\]

possivelmente infinito-dimensional.

O Teorema do Representer reduz a busca aos coeficientes: \[\alpha_1,\ldots,\alpha_n\]

\[ \boxed{ \text{problema funcional} \rightarrow \text{representação finita} } \]

O papel de \(\lambda\)

\[ \sum_i(y_i-f(x_i))^2+ \lambda\|f\|_{\mathcal H}^2 \]

\[\lambda\downarrow\Rightarrow\text{mais flexibilidade}\]

\[\lambda\uparrow\Rightarrow\text{mais regularização}\]

O compromisso viés–variância continua presente.

Uma visão unificada

Podemos controlar a complexidade de \(r(x)\) por:

  • representação;
  • seleção de variáveis;
  • magnitude dos coeficientes;
  • tamanho da vizinhança;
  • complexidade da própria função.

Um princípio recorrente

\[ \boxed{ \text{perda empírica} + \lambda\times\text{complexidade} } \]

Essa estrutura apareceu em Ridge, smoothing splines e agora em RKHS.

Quatro ideias para levar

  1. Nadaraya–Watson é uma regressão constante local.
  2. Regressão linear local ajusta uma reta diferente em cada vizinhança.
  3. RKHS permite pensar em regularização diretamente sobre funções.
  4. O Teorema do Representer produz uma representação finita baseada nos dados.
