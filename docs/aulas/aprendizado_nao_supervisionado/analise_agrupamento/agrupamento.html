Parte III : Aprendizado não supervisionado

Análise de agrupamento

Análise de Agrupamento

Análise de Agrupamento

Até este momento estudamos métodos para representar os dados em um espaço de menor dimensão.

Agora surge uma nova pergunta:

Será que existem grupos naturais nos dados?

A análise de agrupamento (Cluster Analysis) procura responder essa questão, identificando automaticamente conjuntos de observações semelhantes entre si.

Análise de Agrupamento

Características importantes:

  • não existem rótulos conhecidos;
  • o algoritmo deve descobrir a estrutura dos dados;
  • observações semelhantes devem pertencer ao mesmo grupo.
Importante

A análise de agrupamento é um problema clássico de aprendizagem não supervisionada.

Aprendizagem supervisionada × não supervisionada

Aprendizagem Supervisionada Aprendizagem Não Supervisionada
Classes conhecidas Classes desconhecidas
Variável resposta disponível Não existe variável resposta
Classificação Agrupamento
Regressão Descoberta de padrões

Nota

Enquanto os métodos supervisionados aprendem a partir de exemplos rotulados, os métodos de agrupamento procuram identificar padrões presentes apenas nas variáveis explicativas.

O que caracteriza um grupo?

Intuitivamente, um agrupamento deve apresentar duas propriedades:

  • Alta similaridade interna: observações pertencentes ao mesmo grupo devem ser semelhantes entre si.

  • Baixa similaridade externa: observações pertencentes a grupos diferentes devem ser suficientemente distintas.

Esses dois objetivos geralmente são conflitantes e dependem da forma como a similaridade é definida.

Importante

Não existe uma definição única de “grupo”.

Cada algoritmo utiliza um conceito diferente de proximidade e similaridade.

Existe um algoritmo ideal?

Diferentes algoritmos são adequados para diferentes estruturas dos dados.

Estrutura dos dados Algoritmo mais indicado
Grupos aproximadamente esféricos K-means
Estruturas hierárquicas Agrupamento Hierárquico
Estruturas não lineares Agrupamento Espectral
Nota

A escolha do algoritmo depende da geometria dos dados e da definição de similaridade adotada.

Como medir a semelhança entre observações?

A ideia central da análise de agrupamento é reunir observações semelhantes.

Mas surge uma questão fundamental:

Como medir o quão semelhantes são duas observações?

Para isso, utilizamos medidas de distância ou medidas de similaridade.

Quanto menor a distância entre duas observações,

mais semelhantes elas tendem a ser.

Importante

A escolha da medida de distância influencia diretamente os grupos encontrados.

Distância Euclidiana

A distância Euclidiana corresponde ao comprimento do segmento de reta que liga duas observações.

Para duas observações \(\mathbf{x}_i=(x_{i1},\ldots,x_{ip})\) e \(\mathbf{x}_j=(x_{j1},\ldots,x_{jp})\), a distância Euclidiana é dada por

\[ \boxed{ d(\mathbf{x}_i,\mathbf{x}_j)= \sqrt{ \sum_{k=1}^{p} (x_{ik}-x_{jk})^2 } } \]

Observação

O algoritmo K-means utiliza, por padrão, a distância Euclidiana.

Outras medidas de distância

Dependendo do problema, outras medidas podem ser mais adequadas.

Medida Aplicações
Euclidiana Dados contínuos
Manhattan Dados urbanos, trajetórias em grade
Mahalanobis Variáveis correlacionadas
Cosseno Textos, documentos e embeddings
Jaccard Dados binários e conjuntos
Nota

Não existe uma medida universalmente melhor.

A escolha depende da natureza dos dados e do objetivo da análise.

A importância da padronização

Considere duas variáveis:

  • Idade (anos): valores entre 18 e 80;
  • Renda (R$): valores entre 2.000 e 50.000.

Ao calcular a distância Euclidiana, a variável com maior escala tende a dominar o cálculo.

A importância da padronização

Por esse motivo, é comum padronizar os dados antes da análise de agrupamento.

\[ \boxed{ z= \frac{x-\mu}{\sigma} } \]

A padronização garante que todas as variáveis contribuam de forma equilibrada para o cálculo das distâncias.

Algoritmo K-médias

Por que o nome K-médias?

O nome do algoritmo possui dois significados importantes.

O parâmetro K

Representa o número de grupos que desejamos encontrar.

Exemplos:

  • \(K=2\)
  • \(K=3\)
  • \(K=5\)

Esse valor deve ser definido antes da execução do algoritmo.

Por que o nome K-médias?

A palavra médias

Cada grupo é representado por um centróide, calculado como a média das observações pertencentes ao grupo.

\[ \boxed{ \mu_k = \frac1{n_k} \sum_{i\in C_k} x_i } \]

Nota

Cada centróide representa o “centro” de um grupo.

Ideia intuitiva

O algoritmo K-médias procura encontrar

  • um centróide para cada grupo;
  • a melhor atribuição das observações aos centróides.

O processo ocorre de forma iterativa:

  1. Inicializar os centróides.

  2. Atribuir cada observação ao centróide mais próximo.

  3. Recalcular os centróides.

  4. Repetir até a convergência.

Ideia intuitiva

O algoritmo alterna continuamente entre atribuir observações e atualizar centróides.

Etapa 1: Atribuição das observações

Mantendo os centróides fixos, cada observação é atribuída ao centróide mais próximo.

Matematicamente,

\[ \boxed{ C_i = \arg\min_k d(x_i,\mu_k) } \]

onde

  • \(x_i\) representa uma observação;
  • \(\mu_k\) representa o centróide do grupo \(k\).
Nota

Cada observação pertence ao grupo cujo centróide apresenta a menor distância Euclidiana.

Etapa 2 — Atualização dos centróides

Após definir os grupos, cada centróide é recalculado utilizando a média das observações pertencentes ao grupo.

\[ \boxed{ \mu_k = \frac1{n_k} \sum_{i\in C_k} x_i } \]

Assim, os centróides deslocam-se para posições mais representativas dos grupos.

Observação

Os novos centróides geralmente ocupam posições diferentes das posições iniciais.

Algoritmo K-médias

  1. Escolher o número de grupos \(K\).

  2. Inicializar os centróides.

  3. Atribuir cada observação ao centróide mais próximo.

  4. Atualizar os centróides.

  5. Repetir os passos 3 e 4 até que não ocorram mudanças significativas.

Importante

O algoritmo converge porque, a cada iteração, a variabilidade interna dos grupos nunca aumenta.

O que exatamente o algoritmo está tentando otimizar?

O objetivo do K-médias é formar grupos

  • internamente homogêneos;
  • externamente bem separados.

Em outras palavras, o algoritmo procura tornar cada grupo o mais compacto possível.

Quanto mais próximas as observações estiverem do centróide, melhor será o agrupamento.

A qualidade de um agrupamento é medida pela proximidade das observações em relação ao centróide do seu grupo.

Variabilidade dentro de um grupo

Considere um grupo

\[ C_k \]

Cada observação possui uma distância até o centróide

\[ \mu_k \]

Essas distâncias medem o espalhamento interno do grupo.

Quanto menores forem essas distâncias, mais compacto será o agrupamento.

Soma dos Quadrados Intra-Grupos

Para um grupo, a variabilidade é medida por

\[ \boxed{ W_k = \sum_{x_i\in C_k} \|x_i-\mu_k\|^2 } \]

A variabilidade total é

\[ \boxed{ WCSS = \sum_{k=1}^{K} \sum_{x_i\in C_k} \|x_i-\mu_k\|^2 } \]

Soma dos Quadrados Intra-Grupos

onde

  • \(x_i\) representa uma observação;
  • \(\mu_k\) representa o centróide do grupo \(k\).
Nota

WCSS significa Within-Cluster Sum of Squares.

O problema de otimização

O algoritmo procura resolver

\[ \boxed{ \min_{C_1,\ldots,C_K} \; \sum_{k=1}^{K} \sum_{x_i\in C_k} \|x_i-\mu_k\|^2 } \]

Observe que o algoritmo procura simultaneamente

  • definir os grupos;

  • calcular os centróides.

Esses dois problemas dependem um do outro.

Por isso, o K-médias utiliza um procedimento iterativo.

Por que elevar as distâncias ao quadrado?

Existem três razões principais.

  • Evitar cancelamento entre distâncias positivas e negativas;

  • Penalizar mais fortemente observações muito distantes do centróide;

  • Produzir uma função objetivo diferenciável e conveniente para otimização.

Observação

O uso das distâncias quadráticas faz com que o centróide ótimo seja exatamente a média das observações do grupo.

Por que o centróide é a média?

Considere um único grupo contendo \(n_k\) observações

\[ x_1,x_2,\ldots,x_{n_k}. \]

Mantendo esse grupo fixo, o problema consiste em minimizar

\[ \boxed{ f(\mu) = \sum_{i=1}^{n_k} \|x_i-\mu\|^2 } \]

em relação ao centróide \(\mu\).

Ou seja, queremos encontrar o ponto que torna mínima a soma das distâncias quadráticas até todas as observações.

A solução do problema

Expandindo a função objetivo,

\[ f(\mu) = \sum_{i=1}^{n_k} (x_i-\mu)^2 \]

Derivando em relação ao centróide,

\[ \frac{\partial f}{\partial\mu} = -2 \sum_{i=1}^{n_k} (x_i-\mu) \]

No ponto de mínimo,

\[ \frac{\partial f}{\partial\mu}=0 \]

A solução do problema

Logo,

\[ \sum_{i=1}^{n_k}(x_i-\mu)=0, \]

o que implica

\[ \boxed{ \mu = \frac1{n_k} \sum_{i=1}^{n_k} x_i } \]

Importante

O melhor centróide, no sentido de minimizar a soma dos quadrados das distâncias, é exatamente a média das observações do grupo.

Por que o algoritmo converge?

Em cada iteração, o algoritmo executa duas operações:

  1. Atribuição das observações

    Cada observação é enviada ao centróide mais próximo.

  2. Atualização dos centróides

    Cada centróide é recalculado como a média das observações do grupo.

Por que o algoritmo converge?

Em ambas as etapas, a função objetivo

\[ WCSS= \sum_{k=1}^{K} \sum_{x_i\in C_k} \|x_i-\mu_k\|^2 \]

nunca aumenta.

Importante

A cada iteração, o valor de WCSS diminui ou permanece constante.

O algoritmo encontra sempre a melhor solução?

Infelizmente, não.

O problema de otimização do K-médias é não convexo.

Isso significa que diferentes inicializações podem levar a diferentes soluções.

\[ \boxed{ \text{K-means} \Longrightarrow \text{mínimo local} } \]

Cuidado

O resultado depende da escolha inicial dos centróides.

Como reduzir a dependência da inicialização?

Na prática, duas estratégias são amplamente utilizadas.

Múltiplas inicializações

Executar o algoritmo diversas vezes, mantendo a solução com menor WCSS.

Inicialização K-means++

Selecionar centróides iniciais bem distribuídos, reduzindo a probabilidade de convergência para soluções ruins.

A maioria das implementações modernas utiliza K-means++ como padrão.

Quando o algoritmo termina?

O algoritmo encerra quando ocorre uma das seguintes situações:

  • os centróides deixam de se mover;

  • nenhuma observação muda de grupo;

  • a redução em WCSS torna-se desprezível;

  • é atingido o número máximo de iterações.

Em geral, a convergência ocorre após poucas iterações.

O K-médias sempre converge em um número finito de passos, embora não necessariamente para o mínimo global.

Escolha do número de grupos

O algoritmo K-médias exige que o número de grupos seja definido antes da execução.

Na prática, raramente esse valor é conhecido antecipadamente.

Por esse motivo, diversos critérios foram desenvolvidos para auxiliar na escolha de um valor adequado para \(K\).

Escolha do número de grupos

Os mais utilizados são:

  • Método do Cotovelo (Elbow Method);
  • Coeficiente de Silhouette;
  • Gap Statistic.

A escolha de \(K\) influencia diretamente a qualidade do agrupamento obtido.

Método do Cotovelo

À medida que aumentamos o número de grupos, a variabilidade interna dos grupos diminui.

Essa redução pode ser medida por

\[ WCSS = \sum_{k=1}^{K} \sum_{x_i\in C_k} \|x_i-\mu_k\|^2. \]

O Método do Cotovelo consiste em representar o valor de WCSS em função de \(K.\)

O ponto onde a redução deixa de ser significativa sugere um valor adequado para o número de grupos.

Interpretação do Método do Cotovelo

Inicialmente, cada novo grupo reduz significativamente a variabilidade interna.

Entretanto, a partir de determinado valor, o ganho obtido torna-se cada vez menor.

O cotovelo representa um equilíbrio entre

  • simplicidade do modelo;
  • qualidade do agrupamento.
Observação

Nem sempre o cotovelo é claramente definido.

Coeficiente de Silhouette

O coeficiente de Silhouette avalia simultaneamente

  • a coesão dentro dos grupos;
  • a separação entre grupos diferentes.

Para cada observação, define-se \(a(i)\) como a distância média às observações do próprio grupo, e \(b(i)\) como a menor distância média aos demais grupos.

Coeficiente de Silhouette

O índice é definido por

\[ \boxed{ s(i)= \frac{b(i)-a(i)} {\max\{a(i),b(i)\}} } \]

onde

\[ -1\le s(i)\le1 \]

Interpretação do coeficiente de Silhouette

Valores próximos de \(1\) indicam observações bem agrupadas. Valores próximos de \(0\) indicam observações localizadas na fronteira entre grupos.

Valores negativos indicam provável classificação incorreta.

Valor de \(s(i)\) Interpretação
próximo de 1 excelente agrupamento
próximo de 0 fronteira entre grupos
menor que 0 provável grupo incorreto
Observação

Na prática, utiliza-se a média dos coeficientes de Silhouette para comparar diferentes valores de \(K.\)

Critérios para escolha do número de grupos

Critério Ideia principal Melhor valor
Método do Cotovelo redução de WCSS ponto de inflexão
Silhouette separação entre grupos maior valor médio
Gap Statistic comparação com dados aleatórios maior Gap

Cada critério fornece uma perspectiva diferente sobre a estrutura dos dados.

Por esse motivo, é recomendável utilizar mais de um método na escolha de \(K.\)

Observação

Em aplicações práticas, o Método do Cotovelo e o coeficiente de Silhouette são frequentemente utilizados em conjunto.

Efeito da escolha do número de grupos

A escolha do número de grupos influencia diretamente a interpretação dos dados.

Uma mesma base pode produzir agrupamentos bastante diferentes dependendo do valor adotado para \(K.\)

Valor de \(K\) Consequência
Pequeno Grupos distintos são fundidos.
Adequado A estrutura natural é bem representada.
Grande Um mesmo grupo é dividido em vários subgrupos.

O objetivo não é obter o maior número possível de grupos, mas encontrar uma representação simples e consistente da estrutura dos dados.

Efeito da escolha do número de grupos

O melhor valor de K depende do objetivo da análise e da estrutura dos dados. Os critérios estatísticos auxiliam essa escolha, mas a interpretação do problema continua sendo fundamental.

Limitações do algoritmo K-médias

Embora seja um dos algoritmos mais utilizados, o K-médias apresenta algumas limitações importantes.

  • exige a definição prévia do número de grupos;

  • assume grupos aproximadamente esféricos;

  • é sensível à inicialização dos centróides;

  • apresenta dificuldade para identificar estruturas hierárquicas.

Essas limitações motivaram o desenvolvimento de outros métodos de agrupamento.

Importante

Nem todos os conjuntos de dados possuem grupos aproximadamente circulares.

Agrupamento Hierárquico

Agrupamento Hierárquico

O agrupamento hierárquico constrói sucessivamente grupos maiores a partir das observações individuais.

Em vez de produzir apenas uma partição dos dados, o algoritmo constrói uma estrutura em árvore, denominada dendrograma.

Essa representação permite visualizar agrupamentos em diferentes níveis de detalhamento.

O número de grupos pode ser definido posteriormente por meio do corte do dendrograma.

Formação sucessiva dos grupos

Inicialmente, cada observação constitui um grupo independente.

A cada etapa, os dois grupos mais próximos são unidos.

Esse processo continua até que todas as observações pertençam a um único grupo.

O agrupamento hierárquico é um processo sucessivo de fusões entre grupos.

Formação sucessiva dos grupos

Algoritmo Hierárquico Aglomerativo

O procedimento pode ser resumido em quatro etapas.

  1. Inicializar cada observação como um grupo.

  2. Calcular as distâncias entre todos os grupos.

  3. Unir os dois grupos mais próximos.

  4. Atualizar as distâncias e repetir o processo.

O algoritmo termina quando todas as observações pertencem ao mesmo grupo.

Construção do dendrograma

O dendrograma registra todas as fusões realizadas pelo algoritmo ao longo do processo de agrupamento.

Cada união representa a combinação de dois grupos.

A altura em que ocorre cada fusão corresponde à distância entre esses grupos.

Importante

O dendrograma é um registro da sequência de fusões realizada pelo algoritmo.

Interpretação dos ramos

Cada ramo do dendrograma representa um agrupamento formado durante a execução do algoritmo.

Quanto menor a altura da união, mais semelhantes eram os grupos que foram combinados.

Uniões realizadas em alturas maiores indicam grupos menos semelhantes.

A altura do ramo representa a distância utilizada para unir dois grupos.

Corte do dendrograma

O agrupamento final é obtido por meio de um corte horizontal no dendrograma.

Cada ramo interceptado pelo corte corresponde a um grupo distinto.

Assim, diferentes alturas produzem diferentes números de grupos.

Importante

O número de grupos não precisa ser definido antes da execução do algoritmo.

Relação entre altura de corte e número de grupos

À medida que o corte é realizado em alturas menores, o número de grupos aumenta.

Por outro lado, cortes realizados em alturas maiores produzem agrupamentos mais amplos.

O dendrograma permite analisar simultaneamente diversas soluções de agrupamento.

Escolha da altura de corte

Em muitos problemas, o melhor ponto de corte coincide com um grande salto nas distâncias entre fusões consecutivas.

Esses saltos indicam que grupos relativamente distintos passaram a ser unidos.

Assim, é recomendável realizar o corte imediatamente antes dessas grandes fusões.

Dica

Grandes espaços verticais no dendrograma costumam indicar boas escolhas para o corte.

Características do agrupamento hierárquico

Vantagens

  • não exige a definição prévia do número de grupos;
  • produz uma representação hierárquica dos dados;
  • permite explorar diferentes níveis de agrupamento.

Limitações

  • custo computacional elevado para grandes bases;
  • decisões de fusão não podem ser desfeitas;
  • sensível à medida de distância e ao método de ligação.
Importante

O agrupamento hierárquico oferece maior flexibilidade de interpretação, porém possui maior custo computacional que o K-médias.

Distância entre grupos

Após as primeiras fusões, cada grupo passa a conter várias observações.

Nesse momento surge uma nova questão:

Como calcular a distância entre dois grupos?

Existem diferentes maneiras de definir essa distância.

Cada definição conduz a um método de ligação (linkage) diferente.

Importante

A definição da distância entre grupos influencia diretamente a estrutura do dendrograma.

Ligação simples (Single Linkage)

Na ligação simples, a distância entre dois grupos é definida como a menor distância entre quaisquer duas observações pertencentes a grupos diferentes.

\[ \boxed{ d(A,B)= \min_{x_i\in A,\;x_j\in B} d(x_i,x_j) } \]

Características:

  • preserva estruturas alongadas;
  • conecta rapidamente grupos próximos;
  • pode produzir o efeito de encadeamento (chaining effect).
Nota

A união ocorre pelos dois pontos mais próximos.

Ligação completa (Complete Linkage)

Na ligação completa, a distância entre dois grupos corresponde à maior distância entre quaisquer duas observações pertencentes aos grupos.

\[ \boxed{ d(A,B)= \max_{x_i\in A,\;x_j\in B} d(x_i,x_j) } \]

Características:

  • favorece grupos compactos;
  • reduz o efeito de encadeamento;
  • é mais sensível a observações extremas.
Nota

A união considera o par de observações mais distante.

Ligação média (Average Linkage)

Na ligação média, a distância entre dois grupos é calculada pela média de todas as distâncias entre pares de observações pertencentes aos dois grupos.

\[ \boxed{ d(A,B)= \frac1{|A||B|} \sum_{x_i\in A} \sum_{x_j\in B} d(x_i,x_j) } \]

Características:

  • utiliza toda a informação disponível;
  • produz agrupamentos mais equilibrados;
  • reduz a influência de casos extremos.
Nota

Representa um compromisso entre os métodos de ligação simples e completa.

Método de Ward

O método de Ward adota uma estratégia diferente.

Em vez de utilizar uma distância entre observações, ele seleciona a fusão que provoca o menor aumento da variabilidade interna dos grupos.

Equivalentemente, procura minimizar o aumento da soma dos quadrados intra-grupos (WCSS).

\[ \boxed{ \Delta WCSS = WCSS_{após} - WCSS_{antes} } \]

Importante

O método de Ward aproxima a ideia utilizada pelo algoritmo K-médias.

Comparação dos métodos de ligação

A mesma base de dados pode produzir dendrogramas diferentes dependendo do método de ligação utilizado.

Essa diferença altera diretamente os agrupamentos obtidos após o corte da árvore.

Observação

O método de ligação influencia tanto a forma do dendrograma quanto os grupos finais.

Agrupamento Espectral

Motivação para o Agrupamento Espectral

Alguns conjuntos de dados apresentam estruturas que não podem ser representadas adequadamente por grupos aproximadamente esféricos.

Nesses casos, algoritmos como o K-médias podem produzir agrupamentos inadequados, mesmo quando os grupos são visualmente bem definidos.

O agrupamento espectral foi desenvolvido para lidar com estruturas complexas, explorando as relações de similaridade entre as observações.

Importante

Em vez de agrupar diretamente os pontos, o algoritmo agrupa um grafo de similaridades construído a partir dos dados.

Ideia intuitiva do Agrupamento Espectral

O Agrupamento Espectral transforma o conjunto de dados em um grafo de similaridade.

Nesse grafo:

  • cada observação é representada por um vértice (nó);
  • observações semelhantes são conectadas por arestas;
  • quanto maior a similaridade, mais forte é a conexão entre os nós.

Ideia intuitiva do Agrupamento Espectral

Assim, o problema deixa de ser “agrupar pontos no espaço” e passa a ser identificar comunidades fortemente conectadas dentro do grafo.

Importante

O Agrupamento Espectral procura separar o grafo em grupos com muitas conexões internas e poucas conexões entre grupos.

Construção do grafo de similaridade

O primeiro passo do Agrupamento Espectral consiste em transformar o conjunto de dados em um grafo ponderado.

Para isso, é necessário definir o grau de similaridade entre cada par de observações.

Quanto maior a similaridade, mais forte será a conexão entre os respectivos nós do grafo.

Construção do grafo de similaridade

As conexões podem ser construídas de diferentes maneiras:

  • ε-vizinhança: conecta observações cuja distância é inferior a um limite \(\varepsilon\);
  • k-vizinhos mais próximos (k-NN): conecta cada observação aos seus \(k\) vizinhos mais próximos;
  • Kernel Gaussiano (RBF): atribui pesos às conexões de acordo com a distância entre as observações.
Importante

A forma de construir o grafo influencia diretamente a qualidade dos agrupamentos obtidos.

Matriz de adjacência (matriz de similaridade)

O grafo de similaridade pode ser representado por uma matriz quadrada denominada matriz de adjacência, indicada por

\[ \mathbf{W}=[w_{ij}] \]

Cada elemento \(w_{ij}\) representa a intensidade da conexão entre as observações \(i\) e \(j\).

Quanto maior o valor de \(w_{ij}\), mais semelhantes são as duas observações.

Matriz de adjacência (matriz de similaridade)

No caso do kernel Gaussiano (RBF),

\[ w_{ij} = \exp\!\left( -\frac{\|x_i-x_j\|^2}{2\sigma^2} \right), \]

onde:

  • \(\|x_i-x_j\|\) é a distância Euclidiana entre as observações;
  • \(\sigma\) controla a largura da vizinhança.
Importante

A matriz \(\mathbf{W}\) descreve completamente o grafo de similaridade utilizado pelo Agrupamento Espectral.

Matriz grau

Além da matriz de adjacência, o Agrupamento Espectral utiliza uma segunda matriz denominada matriz grau, representada por \(\mathbf{D}\)

O grau de um nó corresponde à soma dos pesos de todas as conexões incidentes sobre ele.

Matematicamente,

\[ \boxed{ d_i = \sum_{j=1}^{n} w_{ij} } \]

Matriz grau

A matriz grau é uma matriz diagonal,

\[ \mathbf{D} = \begin{bmatrix} d_1&0&\cdots&0\\ 0&d_2&\cdots&0\\ \vdots&\vdots&\ddots&\vdots\\ 0&0&\cdots&d_n \end{bmatrix} \]

onde cada elemento da diagonal representa o grau de uma observação.

Nota

A matriz grau resume a intensidade total das conexões de cada nó no grafo.

Matriz Laplaciana

A matriz Laplaciana combina a informação de conectividade da matriz grau com as relações de similaridade da matriz de adjacência.

Ela é definida por

\[ \boxed{ \mathbf{L} = \mathbf{D} - \mathbf{W} } \]

onde

  • \(\mathbf{D}\) representa o grau de cada nó;
  • \(\mathbf{W}\) representa a similaridade entre os nós.

Matriz Laplaciana

Cada elemento da matriz Laplaciana mede o equilíbrio entre

  • a conectividade de um nó;
  • suas conexões com os demais nós.

A matriz Laplaciana descreve a estrutura global do grafo e constitui a base matemática do Agrupamento Espectral.

Interpretação da matriz Laplaciana

A matriz Laplaciana combina duas informações fundamentais do grafo:

  • a intensidade das conexões de cada observação (matriz grau);
  • a similaridade entre observações (matriz de adjacência).

Seu papel é medir quanto uma função definida sobre os nós varia ao longo das conexões do grafo.

Quando dois nós fortemente conectados recebem valores muito diferentes, a matriz Laplaciana penaliza essa diferença.

Interpretação da matriz Laplaciana

Assim, o Agrupamento Espectral procura encontrar representações nas quais:

  • observações fortemente conectadas permaneçam próximas;
  • grupos distintos tornem-se naturalmente separáveis.
Importante

A matriz Laplaciana preserva a estrutura de conectividade do grafo e revela suas comunidades por meio de seus autovetores.

Interpretação matemática da matriz Laplaciana

Considere um grafo ponderado com matriz de adjacência \(\mathbf{W}\) e matriz grau \(\mathbf{D}\).

A matriz Laplaciana é definida por

\[ \boxed{ \mathbf{L} = \mathbf{D}-\mathbf{W} } \]

Uma propriedade fundamental é sua forma quadrática:

\[ \boxed{ \mathbf{x}^{\top}\mathbf{L}\mathbf{x} = \frac12 \sum_{i=1}^{n} \sum_{j=1}^{n} w_{ij}(x_i-x_j)^2 } \]

onde \(\mathbf{x}=(x_1,\ldots,x_n)^\top\) representa um valor associado a cada nó do grafo.

Interpretação

  • Se dois nós possuem alta similaridade (\(w_{ij}\) grande), diferenças entre \(x_i\) e \(x_j\) são fortemente penalizadas.
  • Se dois nós possuem baixa similaridade, essa penalização é pequena.
  • Portanto, minimizar \(\mathbf{x}^{\top}\mathbf{L}\mathbf{x}\) produz representações em que nós fortemente conectados recebem valores semelhantes.
Importante

A matriz Laplaciana mede a “energia” da representação do grafo. Quanto menor essa energia, mais coerente é a representação com a estrutura de conectividade.

Autovalores e autovetores da matriz Laplaciana

O problema de minimizar a energia do grafo pode ser formulado como

\[ \min_{\mathbf{x}} \mathbf{x}^{\top}\mathbf{L}\mathbf{x}, \]

sujeito às restrições

\[ \mathbf{x}^{\top}\mathbf{x}=1, \qquad \mathbf{x}^{\top}\mathbf{1}=0. \]

A solução desse problema é obtida resolvendo

\[ \boxed{ \mathbf{L}\mathbf{v} = \lambda\mathbf{v} } \]

onde

  • \(\lambda\) é um autovalor da Laplaciana;
  • \(\mathbf{v}\) é o autovetor correspondente.

Os autovetores associados aos menores autovalores não nulos fornecem uma nova representação dos dados, preservando a estrutura de conectividade do grafo.

Importante

No Agrupamento Espectral, os autovetores da Laplaciana desempenham um papel semelhante ao das componentes principais no PCA: eles definem um novo espaço onde os grupos tornam-se mais facilmente separáveis.

Algoritmo do Agrupamento Espectral

O Agrupamento Espectral transforma os dados para um novo espaço definido pelos autovetores da matriz Laplaciana e, nesse novo espaço, aplica um algoritmo tradicional de agrupamento.

Etapas do algoritmo

  1. Construir o grafo de similaridade dos dados;
  2. Calcular a matriz de adjacência \(\mathbf{W}\);
  3. Calcular a matriz grau \(\mathbf{D}\);
  4. Construir a matriz Laplaciana

\[ \mathbf{L}=\mathbf{D}-\mathbf{W}; \]

Algoritmo do Agrupamento Espectral

O Agrupamento Espectral transforma os dados para um novo espaço definido pelos autovetores da matriz Laplaciana e, nesse novo espaço, aplica um algoritmo tradicional de agrupamento.

Etapas do algoritmo

  1. Calcular os autovalores e autovetores de \(\mathbf{L}\);
  2. Selecionar os \(k\) autovetores associados aos menores autovalores não nulos;
  3. Formar uma nova representação dos dados utilizando esses autovetores;
  4. Aplicar o algoritmo K-médias nesse novo espaço.
Importante

O Agrupamento Espectral não substitui o K-médias. Ele transforma os dados em um espaço onde o K-médias consegue identificar corretamente grupos que originalmente não eram separáveis.

Espaço espectral: onde os grupos tornam-se separáveis

Os autovetores da matriz Laplaciana definem um novo sistema de coordenadas para as observações.

Nesse novo espaço:

  • observações fortemente conectadas no grafo permanecem próximas;
  • observações pertencentes a comunidades diferentes tornam-se naturalmente separáveis;
  • estruturas complexas podem ser transformadas em grupos aproximadamente convexos.

Espaço espectral: onde os grupos tornam-se separáveis

Assim, um algoritmo simples como o K-médias passa a identificar corretamente os agrupamentos.

O Agrupamento Espectral não altera os grupos existentes nos dados; ele altera a forma de representá-los.

library(dplyr)

#--------------------------------------------------
# 1. Gerar a base Two Moons
#--------------------------------------------------

n <- 400
n_meia <- n / 2

theta1 <- runif(n_meia, 0, pi)
theta2 <- runif(n_meia, 0, pi)

dados <- bind_rows(
  data.frame(
    x1 = cos(theta1) +
      rnorm(n_meia, mean = 0, sd = 0.06),

    x2 = sin(theta1) +
      rnorm(n_meia, mean = 0, sd = 0.06),

    estrutura = "Lua 1"
  ),

  data.frame(
    x1 = 1 - cos(theta2) +
      rnorm(n_meia, mean = 0, sd = 0.06),

    x2 = -sin(theta2) + 0.45 +
      rnorm(n_meia, mean = 0, sd = 0.06),

    estrutura = "Lua 2"
  )
)

X <- scale(
  as.matrix(
    dados[, c("x1", "x2")]
  )
)

#--------------------------------------------------
# 2. K-médias no espaço original
#--------------------------------------------------

ajuste_kmeans <- kmeans(
  X,
  centers = 2,
  nstart = 50
)

dados$grupo_kmeans <- factor(
  ajuste_kmeans$cluster
)

#--------------------------------------------------
# 3. Construir a matriz de similaridade W
#--------------------------------------------------

distancias2 <- as.matrix(
  dist(X)
)^2

sigma <- 0.35

W_completa <- exp(
  -distancias2 / (2 * sigma^2)
)

diag(W_completa) <- 0

# Manter apenas os k vizinhos mais próximos
k_vizinhos <- 10

W_knn <- matrix(
  0,
  nrow = nrow(W_completa),
  ncol = ncol(W_completa)
)

for (i in seq_len(nrow(W_completa))) {

  vizinhos <- order(
    W_completa[i, ],
    decreasing = TRUE
  )[seq_len(k_vizinhos)]

  W_knn[i, vizinhos] <-
    W_completa[i, vizinhos]
}

# Tornar o grafo não direcionado
W <- pmax(
  W_knn,
  t(W_knn)
)

#--------------------------------------------------
# 4. Matriz grau e Laplaciana normalizada
#--------------------------------------------------

graus <- rowSums(W)

D_inv_sqrt <- diag(
  1 / sqrt(
    pmax(graus, 1e-12)
  )
)

L_norm <- diag(nrow(W)) -
  D_inv_sqrt %*%
  W %*%
  D_inv_sqrt

# Garantir simetria numérica
L_norm <- (
  L_norm + t(L_norm)
) / 2

#--------------------------------------------------
# 5. Autovalores e autovetores
#--------------------------------------------------

decomp <- eigen(
  L_norm,
  symmetric = TRUE
)

ordem <- order(
  decomp$values
)

autovalores <- decomp$values[ordem]
autovetores <- decomp$vectors[, ordem]

# Para K = 2, utilizar os dois menores autovetores
# e normalizar as linhas, conforme a formulação
# da Laplaciana simétrica normalizada.
Z <- autovetores[, 1:2, drop = FALSE]

normas <- sqrt(
  rowSums(Z^2)
)

Z <- Z / pmax(
  normas,
  1e-12
)

#--------------------------------------------------
# 6. K-médias no espaço espectral
#--------------------------------------------------

ajuste_espectral <- kmeans(
  Z,
  centers = 2,
  nstart = 50
)

dados$grupo_espectral <- factor(
  ajuste_espectral$cluster
)

espaco_espectral <- data.frame(
  v1 = Z[, 1],
  v2 = Z[, 2],
  grupo = dados$grupo_espectral,
  estrutura = dados$estrutura
)
